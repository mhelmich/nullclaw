# Search APIs for agents: free-tier options

Pricing and free quotas can change. Verify the provider's current terms before depending on a quota for production.

## European providers

| Provider | Free allowance | Notes |
|---|---:|---|
| [Staan](https://docs.staan.ai/) | 1,000 requests/month | Search API built on infrastructure shared by Qwant and Ecosia's European Search Perspective. Free API key; strongest fit here for a European search index. |
| [freesea](https://freesea.dev/) | Free API key; quota not clearly published | Independent index with an agent-focused HTTP API and MCP server. No card or trial clock according to its site. Its business model may show clearly labeled sponsored results for commercial-intent queries. Confirm rate limits before relying on it. |
| [Mojeek](https://www2.mojeek.com/services/search/web-search-api/) | No free tier found | UK-based independent search engine with a web search API. Published pay-as-you-go plan starts at £2 per 1,000 queries. |
| [Siftzo](https://www.siftzo.com/) | 1,000 credits/month; no card | EU-hosted web data API for search, crawling, and extraction. More of a web retrieval/scraping service than an independent general search engine. HTTP requests cost 1 credit; browser requests cost 10. |

## Other agent search APIs from the market survey

| Provider | Free allowance | Notes |
|---|---:|---|
| [Tavily](https://www.tavily.com/pricing) | 1,000 API credits/month; no card | Agent-oriented search, extraction, and crawling. Advanced requests may consume multiple credits, so credits are not necessarily one per search. |
| [Exa](https://exa.ai/pricing) | $10 credits/month; no payment method | Search API with MCP access and web, people, company, and scholarly indexes. Search starts at $4 per 1,000 requests. |
| [Brave Search API](https://brave.com/search/api/) | $5 credit/month, about 1,000 Search requests | General web search with AI-oriented context. A card is required at signup even if prepaid spend is set to $0. [Credit details](https://api-dashboard.search.brave.com/documentation/resources/help-feedback). |
| [SerpApi](https://serpapi.com/pricing) | 250 searches/month | Useful for Google-style and other search engine results pages. Paid plans start at $25/month for 1,000 searches. |

## Recommendation

For a European provider, try **Staan** first for its published recurring quota. **freesea** is worth testing if its independent index and MCP support appeal, but verify the free limits. For larger no-card free allowances beyond the European options, compare **Tavily** and **Exa**.

European ownership or hosting does not by itself establish where every part of a search index comes from. Check provider documentation if index provenance or data residency is a requirement.
